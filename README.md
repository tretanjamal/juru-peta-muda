# Juru Peta Muda: Letak Kota dan Kabupatenku

Gim edukasi IPAS SD kelas 3-4 tentang letak kabupaten/kota dan provinsi. Bersama Lang si elang Jawa, murid memakai delapan arah mata angin, membaca legenda peta, memecahkan teka-teki nama wilayah, lalu terbang dari peta Indonesia ke provinsinya sendiri untuk menemukan kabupaten atau kotanya dan memasang nama tetangganya.

Mainkan: https://tretanjamal.github.io/juru-peta-muda/
